## 可复验入口

正常CI命令不变。前端需Node20和锁对应依赖，禁止对共享node_modules联接执行安装。

```text
./mvnw -Dtest=PublicRemediationHttpReviewTest test
./mvnw -Dtest=PublicRemediationHttpReviewTest -Dpublic.review.browser=true test
./mvnw -Dtest=BoardT07HttpIntegrationTest -Dboard.browser-tests=true test
```

Windows使用mvnw.cmd；浏览器默认Chromium，Windows可设置PLAYWRIGHT_CHANNEL=msedge。真实HTTP浏览器仅在显式Java/H2测试期间运行；`playwright.public-http.config.cjs`定位`tests/http`，不会混入默认mock E2E。其他前端命令和纯loopback安全回归见frontend/security-R1文档。

## 残余资料与边界

299条历史缺口分为120参考阻塞/60仅精确采购门槛/119待核实；并非全部影响每个方案，也没有清零。国内螺丝/垫片参考价、安装规则适用范围仍不足，不换算海外价、不要求实时库存/运税/涨幅核价。

TrainingPlan.durationDays存为Integer且覆盖列表计算没有防御性上界。当前应用main代码未发现创建/更新该字段的请求或setter调用，公开请求只传planId；未证明不可信超大输入可达，不执行极值内存实验。未来新增计划维护时需同步冻结时长边界；当前不宣称支持任意大正整数。

本角色没有修改业务实现；新增正确行为HTTP/浏览器测试及本复审文档分别列入提交白名单。旧AUDIT缺陷表征、运行配置、私钥、日志、个人路径和本地证据不进PR。线上HTTPS覆盖、生产数据库、DNS/TLS及Provider均未操作。
