# 训练执行与指导：前端使用及复验

范围：T05、T06客户端、T07管理界面。以contract-v1.md C01–C09与后端实际响应为准，不改旧训练/AI教练/站点/备案、全局API适配或后台算法。

## 用户入口与完整流程

从滑板专业页的训练区域进入“我的训练指导”，或登录后访问`/training-guidance`。新管理入口为`/admin/training-guidance`，原管理后台有链接，路由保留requiresAuth/adminOnly约束。

1. 选择真实可用模板及版本、目标、用户自评、训练日、单次分钟、开始日期，先预览排期，再明确确认建立。预览中的临时任务ID不用于创建；使用创建真实响应的计划ID与version=0。
2. 今日/查看日期、休息、未开始、暂停和漏练依据服务端today展示；未来开始不请求早于开始日的today。打开任务查看实际步骤、建议量、前置、自查、限制与只读安排分段。
3. 点击“查看来源”可展开四类已登记文字摘录、版本、状态、原定位和限制。locator是定位说明，不拼成网页URL，不声称视频理解、专业认证或医学依据。历史记录中的教学快照仍可查看；当前内容失效另显示提醒。
4. 一次只记一个根任务或选定有效分段。完成/部分/未开始、实际整数分钟、主观难度、自查和多选困难分别提交；未开始为0分钟。分段排期与generation记账字段只读，不作为额外必填输入。记录不可直接修改或删除，再练一次新增记录。
5. 服务端确认反馈后立即显示固定回顾和安全提醒，分钟/根任务完成率/动作自评三类统计分开展示。completionRate是0～1比例，显示百分比，不以天数或练习分钟代替完成率，不把自评当掌握认证。
6. 查看建议触发原因、规则版本、计划版本和前后日期/分钟/解锁差异；只有服务端allowedActions允许才可明确接受/拒绝。不会由完成/自查自动推进。暂停、退出保留历史；每次开启恢复表单都需重新选择自评与明确安全确认，勾选不代表症状消失或医疗许可。
7. 计划、练习、建议、调整各有分页。旧快照、记录创建时间与练习日期分别保留。已终结计划按服务端允许操作只读。
8. 在记录回顾输入困难问题，先预览本人上下文/问题/引用，再明确确认AI解释。没有自动Provider请求或自动重试；解释失败不重发反馈、不清空固定回顾/统计，重新预览后才能再确认。409提示刷新；缺依据不伪造引用。

## 写入恢复与竞态

局部api/training适配器保留HTTP status、data.errorCode、legacyConflict和未知传输错误。所有新写入意图生成新requestKey，发送前保存同一已登录浏览器会话的原method/path/payload/key（包括原expectedVersion）。超时、网络未知或5xx仅手动重试原操作；修改表单/刷新计划不改该次payload，不换键盲发。会话存储被阻止时不发送无法恢复的写入；身份变化使旧视图失效，不跨身份自动接管操作。恢复信息不保存token，以会话身份的SHA256隔离；本版本不承诺跨浏览器或退出登录后的恢复。

读写success/catch/finally均受代次与身份守卫；读槽位分离，切换任务/计划/卸载会失效旧响应。写入在途禁止重复提交和离开页面；未知请求可只读核对，但计划切换读取在途时禁重试，且有独立desiredPlanId校验，不能趁plan=null让原反馈抢回视图。清空模板选择会取消旧详情与排期预览。API请求凭据同步绑定提交身份，旧401不能清除新身份。

## 后台闭环

读取真实模板版本或建立标题非空草稿，完整JSON文档维护任务/来源/自查/指导/固定规则映射。JSON语法预览不代替服务端发布校验。创建返回真实模板字符串ID与版本1；编辑带当前expectedVersion并保存为新草稿版本，旧版本不原位覆盖。未保存编辑禁止误发布已读旧内容。发布/停用需要理由和明确确认；停用可显式标记安全纠正，服务端负责关联版本/建议失效及用户提醒，前端展示真实返回状态。登记来源新增仍需后端审核流程，没有假造通用来源登记接口。

```
node node_modules/vitest/vitest.mjs run --pool=forks --maxWorkers=1 --minWorkers=1 --no-cache
node node_modules/@playwright/test/cli.js test e2e/training-guidance.spec.cjs --workers=1
node node_modules/@vue/cli-service/bin/vue-cli-service.js build
```
