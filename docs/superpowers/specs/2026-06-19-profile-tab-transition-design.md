# 个人中心页签过渡设计

## 目标

改善个人中心页签切换时内容瞬间替换、页面高度跳变的问题，并确保概览、成长中心及其他页签始终使用相同内容宽度。

## 交互

- 所有主页签内容放入同一个宽度为 `100%` 的内容舞台。
- 切换前记录旧内容高度，渲染新页签后测量新高度，舞台在约 `280ms` 内平滑过渡。
- 新内容同时从下方 `10px` 淡入，不添加横向滑动或夸张旋转。
- 连续点击页签时取消上一轮清理计时，以当前高度开始下一次过渡。
- 当前页签被再次点击时不重新播放动画。
- 系统启用 `prefers-reduced-motion: reduce` 时立即切换，不执行高度或位移动画。

## 实现边界

- 只修改 `frontend/src/views/ProfilePage.vue` 及新增的针对性测试。
- 所有主页签按钮统一调用 `switchProfileTab(tab)`，不再直接写入 `profileTab`。
- 新增 `profile-tab-host` 和 `profile-tab-view`，二者保持 `width: 100%`、`min-width: 0`。
- 不修改成长中心内部布局、接口请求、业务状态或其他页面。
- 组件卸载时清理动画计时器和行内高度，避免残留状态。

## 验证

- 针对性测试检查统一切换入口、固定宽度舞台、`280ms` 高度过渡、`10px` 淡入和减少动态效果支持。
- 在现有开发服务器的 `/profile` 页面实际切换“概览”和“成长中心”，检查内容宽度一致、页脚无瞬间跳动、快速切换无卡死。
- 按用户要求，不执行前端生产构建。
