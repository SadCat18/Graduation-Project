# 成长中心徽章图鉴与等级路线设计

## 1. 目标

在现有成长中心中增加完整的徽章图鉴和等级进化路线，让用户能够查看已获得的荣誉、未完成目标以及 Lv1 至 Lv10 的成长位置。

本次沿用现有黑、黄、青街头滑板档案风格，不增加一级导航，不改变签到、经验、排行榜和徽章解锁规则，也不增加等级权益、数据库配置表或后台编辑功能。

## 2. 信息结构

成长中心顶部增加二级导航：

1. `成长总览`
2. `徽章图鉴`
3. `等级路线`

默认进入成长总览。三个子页面使用相同内容宽度，切换采用约 280ms 的淡入、上移 10px 和容器高度过渡。

### 2.1 成长总览

保留现有经验卡、每日签到、签到日历和排行榜。现有完整徽章墙缩减为“最近解锁”摘要，展示最近获得的徽章和“查看全部”入口。

### 2.2 徽章图鉴

独立展示全部徽章、收藏完成度、筛选器和徽章详情。

### 2.3 等级路线

使用滑板公园地图展示 Lv1 至 Lv10 的经验门槛、称号、当前等级和下一阶段目标。

## 3. 徽章图鉴

### 3.1 顶部统计

- 显示“已解锁数量 / 总数量”。
- 显示总完成度进度条。
- 分别显示普通、稀有、史诗和传说四档徽章数量。

### 3.2 筛选

- 状态筛选：全部、已解锁、未解锁。
- 稀有度筛选：全部、普通、稀有、史诗、传说。
- 默认顺序为已解锁优先，再按现有后端排序值排列。
- 当前仅有 8 枚徽章，筛选在前端完成，不增加分页接口。

### 3.3 徽章卡片

每张卡片展示：

- 大尺寸街头贴纸徽章。
- 名称和稀有度。
- 达成条件。
- 未解锁徽章的当前值、目标值和进度条。
- 已解锁徽章的解锁日期和“已收入图鉴”印章。

未解锁徽章保留轮廓、名称和条件，以灰度和较低对比度区分，不隐藏达成目标。

### 3.4 徽章详情

点击徽章卡片打开详情。桌面端使用右侧抽屉，移动端使用底部弹层。详情展示完整徽章、说明、稀有度、解锁条件、当前进度、状态和获得时间。

详情支持关闭按钮、遮罩关闭和 `Escape` 关闭。关闭后焦点返回原徽章卡片。

## 4. 等级进化路线

### 4.1 当前身份

顶部摘要展示当前等级、称号、当前总经验和距离下一等级所需经验，例如：

`Lv3 街角常客 | 当前 215 EXP | 距离 Lv4 还需 85 EXP`

Lv10 显示“已抵达当前最高等级”，不显示下一等级经验。

### 4.2 等级称号与门槛

| 等级 | 称号 | 累计经验 |
| --- | --- | ---: |
| Lv1 | 新板入场 | 0 |
| Lv2 | 板感初醒 | 100 |
| Lv3 | 街角常客 | 200 |
| Lv4 | 路线探索 | 300 |
| Lv5 | 街式新锐 | 400 |
| Lv6 | 地形玩家 | 500 |
| Lv7 | 场地焦点 | 600 |
| Lv8 | 城市领滑 | 700 |
| Lv9 | 街头主理 | 800 |
| Lv10 | 滑行传奇 | 900 |

称号只作身份和视觉展示，不代表真实滑板技术认证，也不影响权限、经验发放或其他业务规则。

### 4.3 路线表现

- 桌面端使用横向折线滑板公园路线，节点依次经过平地、斜坡、栏杆和碗池。
- 移动端转为纵向路线，不产生横向滚动。
- 已完成节点使用黑色节点和黄色完成轨迹。
- 当前节点使用青色高亮、滑板定位标记和轻微呼吸效果。
- 未到达节点使用浅灰锁定状态，但仍可查看等级门槛。
- 点击节点展示等级、称号、累计经验门槛、完成状态和阶段说明。

## 5. 数据与组件边界

### 5.1 前端组件

- `GrowthCenterPanel`：维护二级导航和成长总览，不继续承载所有图鉴与路线细节。
- `BadgeGalleryPanel`：负责徽章统计、筛选、卡片列表和详情开关。
- `BadgeDetailDrawer`：负责桌面抽屉和移动端底部弹层。
- `LevelRoadmapPanel`：负责当前身份摘要、路线节点和节点详情。

### 5.2 徽章数据

继续使用 `GET /api/user/badges`。响应已有名称、说明、稀有度、图标编码、解锁状态、解锁时间、当前值和目标值，足以支持图鉴页面，不修改数据库结构。

### 5.3 等级路线接口

新增：

```text
GET /api/user/level-roadmap
```

响应包含：

- 当前等级与当前总经验。
- 下一等级和剩余经验；满级时为空或为 0。
- Lv1 至 Lv10 的等级、称号、累计经验门槛和状态。

等级门槛和称号由后端统一维护，避免前后端重复定义。第一版使用固定配置，不新增等级表或后台管理入口。

## 6. 加载与错误状态

- 成长总览、徽章图鉴和等级路线分别维护加载及错误状态。
- 徽章接口失败不影响签到、经验和排行榜。
- 等级路线接口失败不影响徽章图鉴。
- 失败区域显示简短原因和重试按钮。
- 无徽章数据、筛选无结果、全部解锁和 Lv10 满级均提供专用状态文案。
- 快速切换二级页面时忽略过期响应，避免旧数据覆盖当前页面。

## 7. 动效、响应式与可访问性

- 二级页面切换沿用 280ms 轻柔滑入和高度过渡。
- 当前等级节点只使用轻微呼吸效果。
- `prefers-reduced-motion: reduce` 下停用位移、呼吸和高度动画。
- 二级导航、筛选器、徽章卡片、抽屉和等级节点均支持键盘操作。
- 筛选结果数量变化通过可访问状态区域播报。
- 桌面端徽章为 3 至 4 列，平板为 2 列，手机为 1 列。
- 详情抽屉具有语义标题、焦点约束和焦点返回。
- 已完成、当前和未到达状态不能只依赖颜色区分，需同时使用图标、标签或边框样式。

## 8. 测试范围

### 8.1 后端

- 等级路线返回完整 Lv1 至 Lv10。
- 各等级经验边界正确，包括 0、99、100、899 和 900 经验。
- Lv10 不返回无效的下一等级。
- 称号和现有等级计算规则一致。
- 未登录访问被拒绝。

### 8.2 前端

- 二级导航默认状态和切换正确。
- 徽章状态、稀有度筛选和组合筛选正确。
- 解锁数量、完成度、进度条和日期展示正确。
- 详情抽屉打开、关闭、焦点返回和移动端形态正确。
- 等级节点的完成、当前、未到达状态正确。
- Lv10 满级、接口失败、空结果和减少动态效果状态正确。
- 三个子页面在相同视口下宽度一致。

## 9. 验收标准

1. 用户可以在成长中心内切换成长总览、徽章图鉴和等级路线。
2. 徽章图鉴可以按状态和稀有度筛选，并查看完整详情。
3. 未解锁徽章明确展示条件与当前进度。
4. 等级路线正确显示 10 个等级、已确认称号和经验门槛。
5. 当前等级、已完成等级和未来等级一眼可辨。
6. 桌面和移动端均无横向溢出，三个子页面宽度一致。
7. 新界面不影响现有签到、排行榜、经验发放和徽章解锁。
